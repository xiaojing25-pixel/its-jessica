Personal Project

Full-Stack Yoga Class Platform — Built Entirely with AI 2026

Using Claude Code, I built a production-ready web application for my yoga teaching practice entirely through conversational AI — describing what I wanted in plain language while the AI translated my intent into working code. Features include sign-up flows with capacity limits and rolling availability windows, cancellation flows with confirmation tokens, scheduling logic, guest registration, a liability waiver, automated email notifications, and calendar invites with Zoom integration. The backend runs on Google Apps Script with Google Sheets as the data layer. A full Playwright test suite covers end-to-end flows, API validations, responsive UI checks, and smoke tests.
